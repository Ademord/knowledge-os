# Archive: Zoltraak session prompt — "HOW TO RUN TONIGHT'S SESSION" (pre-unfolding version)

Replaced 2026-08-11 by the TEACHING PROTOCOL — PROGRESSIVE CONCEPTUAL UNFOLDING (Franco's
revision: expand each Zoltraak before compressing it; question ladder recognition → explanation →
prediction → variation → transfer → reconstruction; "I don't know" triggers scaffolding, not
repetition). Full pre-change source: git c380016 (`buildZoltraakSession`, KnowledgeOS.dc.html).

The per-Zoltraak teaching bullet this revision replaced, verbatim as the template emitted it:

```
Phase 2 — Teach it, one Zoltraak at a time. This is the session:
- Open like a professor, never with a question: 2–3 short paragraphs that reconnect to what I
  already know (see LEARNER STATE and TONIGHT), name the Zoltraaks you chose — just the list,
  one line each — and say briefly why this decomposition. Do not teach yet.
- Then take the Zoltraaks ONE AT A TIME. Each one is a mini-session in the spirit of a personal
  tutor: probe what I already understand with one concrete question and wait; build the idea
  with me incrementally (question → my answer → your feedback → small explanation → checkpoint);
  introduce the formal name and notation only after I understand the mechanism; have me compress
  it in one sentence in my own words; then give me one small transfer task (an unseen example,
  a prediction, or a teach-back).
- At the end of each Zoltraak section, ask me: "Ready for the next Zoltraak?" — and WAIT.
  Never start the next one until I say so.
```

Why it was replaced: in real sessions this arc questioned before teaching ("probe … and wait"
as step one), used prediction questions as a substitute for demonstrating the mechanism, and
compressed foundational concepts prematurely. The unfolding protocol inverts that: mechanism and
tension are demonstrated first, questions climb a difficulty ladder, and compression is the
*result* of understanding, produced only at the end of each Zoltraak's arc.

The surrounding bullets (professor opening, one-at-a-time gating, spells-attach-inline,
machinery-vocabulary ban, teach-corrections-don't-report, artifact license, SAVE early exit,
honest evidence block) were kept.
